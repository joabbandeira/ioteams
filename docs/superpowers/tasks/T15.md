# T15 — CLI operacional pelo mesmo núcleo

Spec: `docs/superpowers/specs/2026-10-14-ioteams-v1-design.md`. Esta é uma parcela da especificação aprovada, não uma nova autoridade operacional.

## Entrega

Criar apps/cli com comandos init, doctor, catalog, index, search, plan, run, status, approve, pause/resume/cancel, login. CLI reaproveita serviços compartilhados e os mesmos guards; se server já controla runtime, comunicar pelo canal autenticado local para não abrir segundo escritor. Flags e saída JSON opcionais, exit codes úteis, não imprimir segredo/cookies/auth. init cria apenas dirs/config do produto no destino explícito; doctor verifica Node24, Codex/capacidades, Git, corpus, disco e auth sem criar inferência. login conduz fluxo nativo do runtime separado; testes fake sem autenticação real. Build e documentação curta de execução local. Tests subprocess in temp roots com corpus fixture e fake adapter, paridade de estados/approval e interrupção.

## Critérios de aceite

- CLI executa fluxo completo com os mesmos serviços, políticas e estados da API.
- Diagnóstico, login isolado, saída segura e comandos de controle têm testes de integração.
