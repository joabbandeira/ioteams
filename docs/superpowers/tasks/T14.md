# T14 — API autenticada local e SSE persistente

Spec: `docs/superpowers/specs/2026-10-14-ioteams-v1-design.md`. Esta é uma parcela da especificação aprovada, não uma nova autoridade operacional.

## Entrega

Criar apps/server (Node http ou framework pequeno justificado) expondo serviços compartilhados do runtime. Loopback 127.0.0.1 apenas; sessão cookie HttpOnly/SameSite e proteção Origin/CSRF com bootstrap local seguro que não expõe tokens em URL/log. REST /api/v1 para catálogo, projetos, demandas/planos/aprovação, sprints/tarefas, runs/pause/resume/cancel, approvals, knowledge/search. Validar request/response com core schemas, corpos limitados, errors sem segredo, idempotency keys em efeitos, optimistic version. SSE com event IDs persistidos, Last-Event-ID, heartbeat, cleanup e reconnect; sem streaming credenciais/transcrições privadas. Server lifespan explícito, injectable fake runtime para tests. API altera domínio somente pelos serviços; never arbitrary shell endpoint. Tests autenticado/unauth/origin/replay/conflict/SSE reconnect.

## Critérios de aceite

- API local valida contratos, autenticação, origem e efeitos idempotentes.
- Eventos SSE persistem e reconectam sem perda/duplicação indevida.
